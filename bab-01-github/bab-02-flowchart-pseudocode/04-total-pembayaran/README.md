# Bab 2 - flowchart dan pseudocode
## Tujuan
Merepresentasikan solusi algoritik menggunakan IPO, pseudocode, dan flowchart.
## Daftar contoh
1. Luas dan keliling persegi panjang
2. Konversi suhu Celsius
3. Rata-rata tiga nilai
## Hasil pengujian
Tuliskan data uji dan hasil yang diharapkan.
## Catatan
Tuliskan temuan, kesalahan yang ditemukan, atau perbaikan yang dilakukan
